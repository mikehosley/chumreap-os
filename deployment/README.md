# Deployment Localization — deliberately blank

This folder is the adaptation layer. The software ships jurisdiction-neutral;
**this folder is where it becomes lawful somewhere specific.**

Every file here is a blank template for one professional concern. Each names the
qualified professional who should fill it in, lists the questions that need answers,
and ends with a sign-off block. Nothing here is advice — the questions are the product.

**The rule:** this software is not deployable with this folder empty. Fill each file
for your region, state, and national government, have each professional sign their
section, and keep the completed folder with your deployment records.

If a concern does not apply in your jurisdiction, say so in the file and say why —
"not applicable" is an answer, but it has to be a considered one.
