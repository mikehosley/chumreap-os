# Other — the big catch-all

> **Deliberately blank, deliberately big.** Every jurisdiction has requirements that don't fit the other files. This is where they go.

## Who fills this in
Whoever the requirement belongs to. If you don't know who that is, that's the first thing to find out.

## How to use this file
For each additional concern in your jurisdiction, add a section below with:
1. **What it is** — the requirement, in one paragraph
2. **Who owns it** — the professional or authority responsible
3. **Status** — not started / in progress / complete / not applicable (with reason)

## Prompts to get started (not advice — delete what doesn't apply, add what does)
- [ ] Import/export rules (equipment, goods crossing borders)
- [ ] Telecommunications rules (if operating messaging, voice, or alerting infrastructure)
- [ ] Financial-services regulation (if holding resident funds, even briefly)
- [ ] Accessibility requirements beyond building code (digital accessibility of resident interfaces)
- [ ] Environmental and waste rules (food waste, medical waste if applicable)
- [ ] Religious and cultural observances affecting operations (holidays, dietary law, prayer times)
- [ ] Emergency planning obligations (fire, flood, medical emergency procedures)
- [ ] Record-keeping rules not covered elsewhere (what the state requires you to keep)
- [ ] Anything your counsel, accountant, or broker asked about that has no file yet
